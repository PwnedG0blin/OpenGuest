# Stratovo 1.0 Beta 7 · Midnight

Stratovo's new Midnight workspace brings Windows, Android and Ubuntu into one
clear dashboard. Start or reopen each system from the persistent launch bar;
open settings and help only when needed. The illustrated system cards show the
actual setup/running state. Your existing guest data folder is retained.

- Midnight navy, turquoise and violet, with bundled system illustrations.
- Native Apple Liquid Glass for navigation and launch controls on macOS 26+.
  Select Automatic, Liquid Glass or Classic in Settings. Reduced transparency
  and increased contrast take priority; macOS 14/15 retain solid controls.
- Larger Help, Diagnostics and Refresh click targets with clear tooltips.
- A consistent text-input dialog for one or multiple lines. Sending line breaks
  as Enter still needs explicit consent; editing the text resets that consent.
- Shared, smaller workspace views and a distinct authenticated private-beta
  update channel. Public betas continue to update through public GitHub Releases.
- Player fixes for hover-dependent redraw, ARM64 memory access and the startup
  cover after a Windows restart. Run **3D-Player vorbereiten / aktualisieren**
  once with Windows shut down to update an existing graphics runtime.

This is a continuing **beta / prerelease**, not a stable 1.0 release. Windows
3D remains experimental. The public package does not include private firmware
or private compatibility extensions. The private beta remains a separate build.

Automatic guest partition resizing (including safe shrinking) is **not included**.
Changing virtual disk capacity still does not automatically resize Windows C:.
No cleanup command is generated or included with the app or installer.
