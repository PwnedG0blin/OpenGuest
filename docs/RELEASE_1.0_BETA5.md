# Stratovo 1.0 Beta 5

The selected Stratovo S artwork is now the macOS app icon in Finder and the Dock.
The source artwork is packaged without redesign; macOS creates the required
standard and Retina icon sizes during the build.

`Aufraeumen.command` previews recognized old Pixelkoje/Stratovo installers and
build folders. After the current app is installed, tested and closed, type
`BETA5 GETESTET` to move the displayed items to the macOS Trash. The current app
and package, all guest disks, GraphicsLab, backups and exchange files stay in
place. The Trash is never emptied. Keep any personal source changes before
trashing old build folders; use Put Back in Trash to restore moved packages.

The resizable native Metal window and optional Steam download write-limit
comparison from [Beta 4](RELEASE_1.0_BETA4.md) remain. Start with Off; compare
40 MiB/s only if needed. This limit applies to all Windows system-disk writes
on the next start and can lengthen installation. Gaming performance and actual
Windows responsiveness still require live testing on the user's Mac.
